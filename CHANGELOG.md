# Changelog

## [v2.5.1] — 2026-11-27

### Fixed
- **Bash-ОС** (`os_bash.h`) — восстановлена рабочая версия 1.3 с цветами, математикой и `sys`.
- **Известные ошибки** — исправлены баги с `mul` (умножение) и делением на ноль.
- **Заголовок** — теперь отображается `hOS v1.3` (вместо v2.2).

### Added
- **Подробный `help`** — каждая команда с описанием (основные, время, файлы, память).
- **`clear`** — очистка экрана с сохранением заголовка.
