Язык h

Легкий, быстрый и открытый язык программирования для Termux и Android. Всё, что нужно знать — в одной шпаргалке.

Скачать приложение

Основы и вывод

Всё начинается с команды say. Она выводит текст на экран.

say Привет, мир! # Если нужно вывести переменную, просто напиши её имя: let name = Вася say name

Цветной вывод

Можно красить текст прямо в терминале. Доступно 4 цвета:

red Ошибка! green Успех! yellow Внимание! blue Информация

Математика

Базовые операции и математические функции.

# Арифметика add 10 5 # Сложение (15) sub 10 5 # Вычитание (5) mul 10 5 # Умножение (50) div 10 5 # Деление (2) # Математические функции sqrt 25 # Квадратный корень (5) pow 2 3 # Возведение в степень (8) abs -5 # Модуль (5) round 3.7 # Округление (4) pi # Число Пи (3.1415...)

Переменные и ввод

Переменные создаются через let. А чтобы спросить что-то у пользователя, используется input().

let x = 10 let name = Вася # Ввод с клавиатуры let answer = input() # Превратить текст в число let num = number answer

Условия (if/else)

Позволяют выполнять код только при определенных условиях.

let x = 10 if x > 5 say x больше пяти else say x меньше или равно пяти end

Циклы (for / while)

Повторяют код несколько раз. for работает с диапазоном чисел.

# Цикл for (от 1 до 3) for i in 1 3 add i 0 # Выведет 1, 2, 3 end # Цикл while (пока x меньше 5) let x = 0 while x < 5 add x 0 let x = add x 1 end

Массивы

Списки данных, доступ к которым идет по индексу (начиная с 0).

let nums = [10, 20, 30] say nums[0] # Выведет 10 say nums[2] # Выведет 30

Функции

Позволяют вынести повторяющийся код в отдельный блок.

func square(n) return n * n end # Вызов функции (без скобок) square 5

Время и фичи Android

В языке есть встроенные команды для работы со временем и управлением телефоном (в приложении).

# Время now # Текущая дата и время year # Год month # Месяц day # День # Управление телефоном (в приложении) vibrate 1000 # Вибрация (в миллисекундах) flash on # Включить фонарик notify Привет # Показать уведомление

Пример: Угадай число

Вот как выглядит полноценная игра на языке h:

let secret = 42 say "Угадай число от 1 до 100:" let guess = input() let g = number guess if g == secret say "Угадал!" end if g < secret say "Мало" end if g > secret say "Много" end
