Два движка

У языка h есть два независимых движка:

  • Node.js (h) — для игр и сложной логики (циклы, функции, массивы).
  • C (h2c) — быстрый движок для математики, сетей и системных команд.

В зависимости от задачи используй тот или иной движок.

Основы (Node.js и C)

Вывод текста и цветной вывод доступны в обоих движках.

say Привет, мир! # Текст без кавычек let name = Вася say name # Выведет значение переменной # Цвета (работают в обоих движках) red Ошибка! green Успех! yellow Внимание! blue Информация

❌ Неправильно: say("Привет") — не ставь скобки.

Математика (C-движок)

В C-движке (h2c) есть базовые арифметические команды и корень.

add 10 5 # Сложение (15) sub 10 5 # Вычитание (5) mul 10 5 # Умножение (50) div 10 5 # Деление (2) sqrt 25 # Квадратный корень (5.00)

В Node.js-версии математика делается через переменные и стандартные операторы (например, let x = 5 + 5).

Ввод (input)

Ввод с клавиатуры есть в обоих движках, но работает по-разному.

# C-движок (числа) input age say age # Node.js (текст и числа) let answer = input() let num = number answer

❌ В C-движке нельзя использовать скобки: input(age).

Условия (if/else)

В Node.js есть полный if/else, в C-движке — только if.

# Node.js (полный) if x > 5 say Больше else say Меньше end # C-движок (только if) if x > 5 say Больше end

❌ Не используй фигурные скобки { } — только слово end!

Циклы (только Node.js)

Циклы for и while есть только в Node.js-версии.

# Node.js for i in 1 3 say i end let x = 0 while x < 5 say x let x = x + 1 end

❌ В C-движке циклов нет (они не поддерживаются).

Массивы (только Node.js)

Массивы поддерживаются только в Node.js-версии.

# Node.js let nums = [10, 20, 30] say nums[0] # Выведет 10

Функции (только Node.js)

Функции с return есть только в Node.js.

# Node.js func square(n) return n * n end square 5

Время (оба движка)

В обоих движках есть команда now.

now # Текущее время (C: 18:41:04, Node: дата и время)

Сеть и системные команды (только C)

В C-движке (h2c) есть команды для работы с интернетом и ОС.

# Сетевой запрос (через curl) net https://api.github.com # Системная команда sys ls -la sys node ./h rpg_v250.h

REPL (интерактивный режим)

Запусти ./hrepl, чтобы тестировать команды без создания файлов.

h> say "Привет" Привет h> add 5 10 15 h> if 10 > 5 ... (введи тело и 'stop') h> say "Работает!" h> stop Работает!
