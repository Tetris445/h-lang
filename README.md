# h — Язык программирования

**h** — это легковесный, быстрый и открытый язык программирования, созданный для работы в Termux и Android. Изначально написан на Node.js, но также имеет движок на C для максимальной производительности.

## ⚡ Два движка: Node.js и C

Язык `h` работает на двух движках, каждый для своих задач:

1. **Node.js (`./h`)** — основной интерпретатор. Поддерживает все команды: условия, циклы, функции, массивы, `input()`, цвета и время. Идеален для обучения и веб-разработки (работает в онлайн-песочнице на сайте).
2. **C (`./h2c`)** — экспериментальный движок на C. Пока поддерживает только команду `say`, но работает в разы быстрее, так как компилируется напрямую в машинный код. В будущем получит поддержку математики и логики.
