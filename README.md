# h — Язык программирования

**h** — это легковесный, быстрый и открытый язык программирования, созданный для работы в Termux и Android.



- **Bash-ОС (`os_bash.h`)** — интерактивный REPL на чистом Bash (без C и clang).
- **Карективы (`hprep` + `corecto.h`)** — поддержка синтаксиса `say {"..."}` и `import:{"..."}`.
- **Библиотеки на чистом h** — `math.h`, `colors.h`, `graphics.h`.
- **Виртуальная машина (`hvm_asm_nolibc`)** — поддержка `say`, `let`, `add`, `if`, `while`, `sleep`.
- **Указатели памяти** (`P1`–`P5`) в VM.
- **Цвета** в Bash-ОС (ошибки красным, результаты жёлтым).

## 🏗️ Архитектура

У `h` есть несколько независимых способов запуска:
1. **Bash-ОС** — самый чистый и быстрый (без C, без clang).
2. **Виртуальная машина** (`hvm_asm_nolibc`) — низкоуровневая, с указателями.
3. **Компилятор в машинный код** (`hbridge build` + `clang`) — для bare-metal.

## 📝 Пример кода

```h
say {"Hello, world!"}
let x = 10
add x + 5
if x > 5
    say {"Больше"}
end
